用户观察到故障发生在游戏重负载加载处。日志与短暂绘图停顿相符，但未记录各条 VI／NV 调用耗时，因此不能区分 CPU 调度、取显示缓冲、同步栅栏或其他显示服务等待，也不能据此证明内存不足。

原实现将绘图停顿与采样停止一样处理，直接 Engine::stop(Reason::Renderer)，进入 Paused 并移除虚拟按键。需要区分短暂的显示等待和真正停止输入的情形；采样超时、HOME、Sleep、应用切换及真实显示错误的处理仍需保留。

本次读取阶段没有修改 SD 文件。磁盘管理查询的自动权限审核曾超时，但已通过允许的普通文件读取成功取得日志；不是日志损坏或卡读取失败。
