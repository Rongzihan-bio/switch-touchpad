# 1.1.0-beta.2：肩键与侧滑

2026-10-01，按用户要求补齐 L1/L2/R1/R2，不增加 L3/R3，同时为无实体手柄的休眠恢复提供菜单入口。街机八方向功能随本包提供，配置仍兼容旧版 v1；没有保存过街机模式的卡默认继续使用模拟模式。

## 按键

| 屏幕标签 | Switch 输出 | 固定中心（1280×720） |
|---|---|---|
| L1 | L | (120,350) |
| L2 | ZL | (240,350) |
| R1 | R | (1040,350) |
| R2 | ZR | (1160,350) |

肩键与 ABXY 同为半径 36 的圆形按钮，随控件大小缩放，中心固定。滑入按下、滑出或抬手释放；支持方向、ABXY 和肩键同时操作。同一键的多指触摸合并，最后一指离开才释放。被摇杆捕获的手指即使移动到肩键上也不额外触发肩键。ZL/ZR 为数字按键。

## 侧滑

SD 的 `switch/.overlays/ovlmenu.ovl` 含 Ultrahand 标识与 `swipe_to_open` 设置；其实际 `config/ultrahand/config.ini` 中该项原为 `false`，菜单为左侧（`right_alignment=false`）。本次安装仅将 `[ultrahand]` 的 `swipe_to_open` 改为 `true`，保留原 `ZL+ZR+DDOWN`、其他配置及主菜单／加载器程序。

单改全局开关不能让旧 libtesla 编译的 Touchpad 自动支持侧滑。因此本版在 Touchpad 的隐藏输入轮询中增加独立识别器，读取同一个 Ultrahand 开关；隐藏中的 Touchpad 可直接被侧滑呼出。

从最左边缘快速向右滑动并抬手。逻辑边界与参考 Ultrahand 源码一致：首点 x≤16，在 150ms 内跨过 x>100。支持配置的右侧菜单与可选 `swipe_offset`（本地支持 0～200，当前卡未设置）。本地额外要求先观察到全抬手状态、单一新触点和同一手指 ID；多指、超时、采样不可用、HOME／睡眠事件、时钟倒退或轮询间隔超过 250ms 会取消候选手势。游戏中从摇杆拖到屏幕边缘再拖回来不算侧滑。

侧滑只发唤出事件，随后仍走已有 UI 线程的 `onShow` → 后台 Pause／输入释放／显示层退出确认 → 显示菜单流程。侧滑手指在抬起前不进入菜单输入，显示菜单时丢弃游戏期间积累的按键及休眠前未结束的菜单触摸状态。未增加新的线程、自动启动或后台内存池调整。

这是菜单呼出功能，不负责从休眠中唤醒主机或替代系统解锁。用户唤醒并回到游戏后，通过侧滑进入 Touchpad，选择“启用并返回游戏”。其他第三方 `.ovl` 隐藏时是否响应侧滑由其自身实现决定。

参考：[Ultrahand 用户文档](https://github.com/ppkantorski/Ultrahand-Overlay/wiki)、[libultrahand 源码](https://github.com/ppkantorski/libultrahand/blob/main/libtesla/include/tesla.hpp)。2026-10-01 下载的参考头 SHA-256 为 `4d5a173c816fb247f2b154dfd93d10125cb994c90435e5236591f91c3f855aeb`；只核对行为与配置，没有引入 libultrahand 依赖或替换用户的菜单二进制。

## 验证

电脑端 ASan／UBSan 测试覆盖肩键位映射、九指组合、滑动释放、同键多指、摇杆触点独占、睡眠中立、各尺寸按钮无重叠、渲染缓冲边界，以及侧滑起点、时间边界、左右侧、偏移、多指／身份变化、休眠取消、时钟跳变、缺失采样和关闭开关。实际半分辨率画布预览见 `controls-preview.png`。

离线 Switch 编译及结构检查通过；后台镜像加主线程栈为 5,066,752 字节（4.8320 MiB），仍使用 Applet 内存池和资源组。未在本轮 SD 安装期间进行实机运行测试。

安装后验收：

1. 完整重启，先用左边缘快速向右滑动打开主菜单，进入 Touchpad。
2. 游戏或应用模式 Input Test 中启动后台、启用；抬手后依次检查 L1/L2/R1/R2 为 1，松手为 0，检查方向＋肩键＋ABXY 组合。
3. 游戏中侧滑，确认显示 Touchpad 菜单且输入中立；抬手时不能误点“启用”。
4. 启用后休眠，再唤醒、返回游戏，不使用实体手柄，侧滑进入菜单并重新启用。
5. 继续检查游戏加载场景和街机方向手感；若异常保留 `config/touchpad` 日志。
