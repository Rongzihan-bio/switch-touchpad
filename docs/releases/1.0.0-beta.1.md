# Touchpad 1.0 Beta

版本：`1.0.0-beta.1`，Git 标签：`v1.0.0-beta.1`，日期：2026-09-26。

本版将用户确认可用的 rc10 保存为首个 1.0 Beta。用户已反馈手柄后台及前台问题解决，原先在游戏加载时触发的绘图超时停用问题得到成功反馈。运行逻辑与 rc10 保持一致，只更新版本及启动日志标识；另整理发布说明、验证记录和打包信息。

## 提供的功能

- 固定左摇杆和 ABXY，支持多点触摸、按钮滑动及松手释放。
- 独立透明显示层，Tesla 提供手动启动、启用、停用及大小、不透明度、死区设置。
- 后台使用 Applet 内存池与资源组，避免早期 System 资源组的启动配额问题。
- 触摸采样正常时持续输入，允许绘图反馈延迟；显示恢复后无需再次启用。
- 附带输入测试程序和 Touchpad Diag 0.3.4。诊断工具本身保持原版，部分输出仍以 rc10 称呼相同配置的后台。

## 已确认与待验证

实机基线为 rc10，用户自报环境是 Switch OLED、HOS 22.5.0、Atmosphère 1.11.2 / E，已安装 Tesla。具体反馈、源码标签和四个程序的 SHA-256 见 [验证记录](1.0.0-beta.1-validation.json)。原始基线标签为 `v0.1.1-rc10`，发布标签为 `v1.0.0-beta.1`。

电脑端验证包括固定离线工具链构建、二进制结构／内存分类检查，以及启用 ASan／UBSan 的触摸、配置、通信、显示栈和超时回归。模拟绘图停顿 24 秒期间，按键和摇杆仍可随采样更新及释放。Beta 版本标识重建后的二进制未额外独立上机；具体游戏兼容性、测量性能、30 分钟持续运行和完整生命周期清单仍待分别记录。

## 已知边界

- 当前布局只有左摇杆和 ABXY；没有右摇杆、十字键、肩键、加减键、拖动布局或完整手柄替代能力。
- 虚拟 Pro Controller 与实体手柄独立，玩家顺序需按实际游戏调整；不屏蔽游戏原生触摸。
- HOME／Tesla／休眠／应用切换等停止后需要手动启用。采样真正停止更新达到 250 ms 和实际服务错误仍会释放输入。
- 所有线程或系统失去响应时，进程内保护无法保证继续执行。旧 rc9 在较晚时间记录过 `001C24CA` 控制器错误，尚未单独定位，不因本次成功反馈而标注为已修复。
- 后台保持手动启动，发布包不包含 `boot2.flag`。没有更改内存配额、固件、Tesla Menu 或加载器。

## 发布附件与安装

- `touchpad-1.0.0-beta.1-sd.zip`：后台、Tesla 插件、输入测试和诊断程序，附文档及许可证。
- `touchpad-1.0.0-beta.1-source.zip`：匹配源码、修改后的 libtesla、构建脚本及测试。
- `touchpad-1.0.0-beta.1-SHA256SUMS`：两个 ZIP 的 SHA-256 清单。

关机并备份本插件文件后，将安装包中的 `atmosphere` 和 `switch` 合并到 SD 根目录；如遗留本插件的 `flags/boot2.flag`，先移除。安全推出，插回后完整重启。在游戏中打开 Tesla → Touchpad，启动后台，再选择“启用并返回游戏”。标题应为 `1.0.0-beta.1`。详细操作见 [README](../../README.md)。

重新命名为 Beta 不要求已经运行正常的 rc10 立即升级；当前 SD 上的已验证版本可继续使用。Git 记录和本地发布附件已经保留这套基线。
