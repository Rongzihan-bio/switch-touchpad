## 1.1 街机模式追加测试

新功能未经过实机确认。更新全部程序并完整重启后，在 Tesla 将模式设为“街机八方向”，先用“十字键”输出，回中区保持默认 20%。

- 输入测试程序逐个检查九个方向状态、抬手及回中归零；数字 5 表示中立。普通模拟模式仍须检查连续幅度。
- 游戏训练模式检查下→右下→右、下→左下→左、右→下→右下、半圈及前→回中→前；左右朝向分别测试。
- 保持手指按住，滑到外圈外，应持续跟随方向；滑回中心或抬手才回中。
- 摇杆与 ABXY 多指并用，确认方向不被另一触点接管。
- 游戏若不接受十字键，再选择“左摇杆”输出，并记录哪一种有效。
- 复测先前重负载加载、HOME 与 Tesla 场景，并检查设置保存、重启及恢复模拟模式。

## 性能测量

测试程序显示输入循环周期（目标约 16.7 ms）、最近有变化的一帧绘图耗时、触摸采样年龄和序列号。这些都是内部指标，不等于从触摸到游戏画面的端到端延迟。

如需测量端到端延迟，使用高帧率摄像同时拍到手指触屏与测试程序按钮变化，至少记录 30 次，报告帧率、样本数、中位数和高分位数。对照启用前后的游戏帧率与其他常驻模块组合。

## 异常测试与恢复

- 初次调试如“画面未就绪”，记录错误码和系统版本，关闭并重启本模块后再试；不要替换现有加载器碰运气。
- `Stale touch`：触摸样本超过 250 ms 未更新，后台已停止映射。可重新启用一次确认；持续发生时记录触点数与采样年龄。
- `Clock gap`／`Timeout`：发生休眠、长时间调度停滞或准备超时，需要重新手动启用。
- `Controller error`：记录十六进制错误码及当时是否打开配对页面／连接实体手柄；重新执行配对或启用。持续失败时重启恢复。
- `Display error`：显示接口返回实际错误。rc10／1.0 Beta 不再因绘图心跳延迟停用。输入会停止，但驱动阻塞时不能保证旧画面即时消失。
- 按计划做生产者停滞验证时，应使用开发调试器，仅暂停采样线程、保留发送线程；确认 250 ms 阈值后中立。正常安装包没有可被误触的故障注入按钮。
- 整个后台强杀／崩溃后的设备清理由系统决定，另行记录，必要时重启。不要把同进程内的心跳保护当作进程退出保护。
